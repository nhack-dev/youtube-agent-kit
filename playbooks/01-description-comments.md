# 01 YouTube（ショート）：説明文とコメント

## 題名・説明文・タグ（新しい動画を出した日）
1. 持ち主から動画IDをもらう（動画のURLの最後の英数字）
2. `templates/yt-description.md` を写して `drafts/yt-<動画ID>.md` に書く
   - 題名：40字前後まで（100字が上限）。中身が分かる言葉＋見る人の得
   - 説明文の1〜2行目：検索や一覧で見える。題名を言い換えて補う
   - 説明文の本文：動画で言ったことの要点を3行・関連動画やプレイリストへの案内
   - ショートは縦長・3分以内の動画。`#Shorts` は目印として1つ入れてもよい（多くは付けない）
   - タグ：5〜10個（動画の中身の言葉だけ）
3. dry-run：`python3 scripts/yt_description.py --video <ID> --file drafts/yt-<ID>.md`
4. 持ち主の OK → `--go`（1回50ユニット）

## コメント
1. `python3 scripts/yt_comments.py fetch --go`
2. `data/yt-reply-drafts.json` の `reply` を書く（感想にはお礼＋相手の言葉を1つ・質問には短く答える・荒らしには返さない）
3. 持ち主の OK → `approve: true` → `send --go`（1回20件まで・1件50ユニット）
